1. 무엇을 모으나

짐매니저는 F45 지점이 쓰는 운영 도구입니다. 구글 로그인을 하면 그 계정의 이메일 주소와 이름(구글이 주는 기본 정보)만 받습니다. 지점 직원 계정에는 이름 · 역할 · 비밀번호(숫자, 해시로만 저장)가 저장됩니다.

2. 회원(지점 고객) 정보

지점의 회원 정보는 지점이 쓰는 글로폭스(ABC Glofox)에 있고, 짐매니저는 지점 PC 의 크롬에 로그인된 글로폭스 화면을 통해 읽고 씁니다. 회원리스트와 명단 파일은 지점 PC(또는 지점이 정한 서버)에만 남고, 운영자가 따로 모아 두지 않습니다. AI(Anthropic Claude)에 일을 시킬 때 회원 이름은 가려서(김*범) 보내고, 연락처 · 이메일은 보내지 않습니다.

3. 어디에 쓰나

  • 로그인하고, 누가 어떤 일을 했는지 기록하는 데
  • 설치를 돕고(구글 드라이브 폴더 공유), 충전 · 이용 요금을 셈하는 데

광고 · 판매에 쓰지 않고, 제3자에게 넘기지 않습니다(법이 정한 경우 제외).

4. 얼마나 두나

계정을 지우면 로그인 정보도 지웁니다. 이용 · 충전 기록은 세금 신고에 필요한 기간 동안 둡니다.

5. 구글 사용자 데이터

짐매니저가 구글 로그인으로 받는 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
